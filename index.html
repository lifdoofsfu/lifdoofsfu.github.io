01

CG 资源分类导航

CG 领域涵盖范围很广，从 2D 插画、角色设定、场景概念到 3D 建模、动画特效和纹理材质，不同方向对应的资源类型差异明显。本栏目按照常见创作需求划分入口，方便你根据项目阶段选择对应类别。

对于刚接触数字绘画的用户，建议先从基础笔刷、色彩参考和人体结构素材入手；有一定经验后，再关注商业项目常用的分层文件、模型拓扑和渲染预设。分类导航的意义在于降低筛选成本，而不是替代系统学习。

每个分类入口通常指向第三方平台或社区，本站仅做整理与说明。访问时请留意目标站点的内容授权方式，避免将仅限个人学习的素材用于商业用途。

  • 2D 插画与角色设计参考
  • 3D 模型、贴图与材质资源
  • 动画分镜与特效素材方向
  • 笔刷、字体与配色工具入口
  • 商业项目常用文件格式说明
02

常用 CG 软件与工具

数字创作离不开软件工具，主流选择包括 Photoshop、Clip Studio Paint、Procreate、Blender、Maya、ZBrush 和 Substance Painter 等。不同工具在绘画、建模、雕刻和纹理绘制方面各有侧重，了解它们的基本定位有助于合理搭配工作流。

除了大型软件，一些辅助工具同样值得关注，例如 PureRef 用于参考图整理，Krita 适合开源绘画需求，Blender 在建模和渲染方面免费且功能完整。选择工具时应优先考虑项目需求和个人习惯，而不是盲目追求最新版本。

安装软件请务必从官方渠道获取，避免使用来源不明的破解版本。部分工具提供教育优惠或免费试用，合理利用这些渠道既能控制成本，也能降低安全风险。

  • 绘画类：Photoshop、Clip Studio Paint、Procreate
  • 建模雕刻：Blender、Maya、ZBrush
  • 纹理渲染：Substance Painter、KeyShot
  • 辅助参考：PureRef、Eagle、Krita
  • 优先选择官方渠道与正版授权
03

学习教程与进阶路径

CG 学习通常遵循从基础到专项的路径。第一阶段建议掌握透视、素描关系、人体结构和色彩原理；第二阶段根据兴趣选择角色、场景或 UI 方向深入；第三阶段通过完整项目练习，把零散知识整合为可交付的作品。

网络教程质量参差不齐，筛选时可以关注讲师是否有完整作品集、课程是否包含作业反馈、内容是否持续更新。免费教程适合入门和查漏补缺，系统课程则更适合需要结构化训练的学习者。

练习量固然重要，但复盘同样关键。建议定期整理自己的作品，对比参考图分析差距，并主动寻求同行反馈。单纯重复而不总结，进步速度往往有限。

  • 基础阶段：透视、结构、色彩与光影
  • 专项阶段：角色、场景、道具或 UI
  • 项目阶段：从草图到成品的完整流程
  • 筛选教程关注讲师作品与更新频率
  • 定期复盘并寻求同行反馈
04

作品展示与灵感获取

寻找灵感是创作流程中的重要环节。ArtStation、Pixiv、Behance 等平台聚集了大量专业作品，适合按标签、风格或媒介浏览。观察他人如何处理构图、光影和叙事，比单纯收藏图片更有价值。

浏览作品时建议带着问题去看，例如画面焦点如何安排、色彩冷暖如何平衡、材质质感如何表现。可以建立自己的参考库，按项目或主题分类，方便后续调用。

尊重原作者是基本前提。参考不等于复制，直接描摹或二次发布他人作品需要获得授权。用于学习分析时，也应避免将他人作品冒充为自己的成果。

  • 按风格、媒介和主题浏览作品
  • 带着构图与光影问题观察
  • 建立个人参考库并分类管理
  • 尊重版权，避免未授权使用
  • 参考用于学习而非直接复制

访问安全与版权提醒

网络资源站点繁多，部分页面可能包含诱导下载、弹窗广告或伪装按钮。访问任何第三方链接前，请确认域名是否正规，避免在不明页面输入账号密码或支付信息。

下载素材和软件时，注意查看文件格式与来源说明。压缩包、可执行文件和脚本尤其需要谨慎处理，建议使用安全软件扫描后再打开。

版权方面，不同素材的授权范围差异很大，常见的有个人使用、署名使用和商业授权等。使用前应阅读许可协议，必要时联系原作者获取书面同意。

  • 确认域名与页面来源是否正规
  • 不轻易输入账号密码或支付信息
  • 下载文件先扫描再打开
  • 阅读素材授权范围与许可协议
  • 商业用途需获得明确授权

社区交流与行业动态

CG 行业更新速度快，新软件版本、新硬件设备和新的制作流程不断出现。关注行业媒体、创作者博客和社区讨论，有助于了解趋势变化，但也要注意区分宣传信息与实际体验。

分享自己的练习和项目同样重要。公开作品可以获得反馈，也能记录成长过程。保持礼貌和开放心态，长期来看比单次提问更有收获。

  • 关注软件更新与硬件趋势
  • 提问时提供软件、问题与尝试记录
  • 分享练习作品获取反馈
